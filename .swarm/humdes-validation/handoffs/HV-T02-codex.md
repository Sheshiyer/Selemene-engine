## Implementation outline
1. **bulk_fetch_v3.py** — copy v2, then in Phase 2 enumerate `data.tabs[*].childs[*]` and click each child label (`get_by_text(child_title)`) inside each reading's natural URL view. Same XHR interception path; expect ~30 captures/reading instead of ~9.
2. **humdes_to_selemene.py** — add `_extract_definition_from_certainty()`, `_extract_centers_from_<x>()`, `_extract_channels_from_<x>()`. Mutate `expected["expected"]` to include `definition`, `defined_centers`, `active_channels`, and ideally all 13+13 activations.
3. **Re-run** the full pipeline on the existing latest bulk2 (no new capture needed if v3 reuses existing data) OR re-capture if v3 needs new sub-tabs.
4. **Re-run normaliser** → fresh `_index.json` + regenerated `*_expected.json` files.
