# Phase 6 Plan 01: Distribution compatibility matrix

## Goal

Pack and test each Selemene-owned distribution surface from clean artifacts, with consumer compatibility fixtures kept inside Selemene.

## Tasks

1. Enumerate Rust, TypeScript, Python, CLI, TUI, admin, Witness, and Hermes package surfaces.
2. Pack/install each dependency-ready surface in an isolated temporary directory.
3. Verify versions, exports, declarations, checksums, and absence of sibling-source links.
4. Run Selemene-owned consumer fixtures and mark unsupported surfaces held rather than compatible.

## Exit condition

Each surface has an artifact identity, command receipt, and explicit installed-runtime status.
