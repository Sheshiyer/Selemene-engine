# Phase 7 Plan 01: Operational proof and promotion hold

## Goal

Complete repository-owned deployment, rollback, monitoring, and asset-provenance validation while keeping live promotion disabled until provider attestations exist.

## Tasks

1. Validate Railway project/environment/service/source selectors against the checked-in manifest.
2. Validate Cloudflare source bindings and record the account-access mismatch as an explicit hold.
3. Validate release receipt fixtures for source revision, schema revision, artifact digests, rollback, and asset inclusion.
4. Record DNS and Pattern Memory decisions with authority owners; do not invent live receipts.

## Exit condition

The repository proves what it can locally and names the exact post-deploy, rollback, and recipient receipts that remain external.
