# Phase 5 Plan 01: Disposable state and authorization proof

## Goal

Turn the existing migration, auth, billing, cache, invitation, and media tests into a phase receipt that proves disposable behavior without touching production state.

## Tasks

1. Inventory existing fixtures and identify the first dependency-ready disposable probe.
2. Run migration validation and, where local PostgreSQL is explicitly available, apply/rollback in a disposable database only.
3. Run auth/RBAC, billing replay, cache, invitation, and media-minimization tests with secrets omitted.
4. Record exact production authorization inputs still missing; do not mutate production.

## Exit condition

Every claimed pass has command output and every unavailable database/provider probe is held with a follow-up owner.
