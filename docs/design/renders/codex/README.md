# Codex render reference set

This first set contains 27 generated PNG originals from 29 October 2026: 17 engine instruments, six workflow instruments, three voice plates and the trinity-hex mark. The selected brand direction is the darker set in [Codex Dark](../codex-dark/); this brighter first pass is retained as a reference.

`prompts.json` records the subject, aspect, requested dimensions and prompt for every image. Engines and workflows are 1024 × 1536 pixels, voice plates are 1536 × 1024, and the mark is 1024 × 1024. The original PNG bytes are preserved in ordinary Git alongside their prompts.

The historical generation notes describe a Codex CLI image run using the Vimshottari still as a style reference. They do not establish a currently available model or provider route. These source assets do not deploy a website or change engine behavior.
