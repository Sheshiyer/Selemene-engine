HOW TO READ THE ATLAS

An architecture.
A correspondence.

Selemene is shown as a Vitruvian body within a circle, square, and five conceptual sheaths. The body and field are an artistic map of software relationships.

NODE
One engine, software service, infrastructure component or consumer. Size distinguishes component roles.
PATH
A relationship described by a repository source. Each component and relationship retains its source path.
ENGINE PART
In an engine view, one sculptural part represents one named software responsibility. Separation reveals the assembly; it does not represent physical hardware. The inspector identifies implemented, simplified, delegated and placeholder paths.
PARTICLE
A schematic directional cue along a relationship. Density and speed do not represent traffic or physiology.
SHEATH
A proposed category correspondence with one of the five Pancha Koshas. Ring spacing is a composition device, not a physical measurement.

The five sheaths are traditionally described as physical, vital, mental, intellectual and blissful. Read the traditional reference ↗

No existing engine-to-kosha assignment was found in the repository. This atlas proposes the grouping, with a rationale for each engine. Anandamaya associates sound and form with contemplation; no engine measures bliss.

Configured components do not imply live availability. Pattern Memory remains labeled as a declared scaffold. No live API, health, camera or sensor requests are made. The three Biofield boundaries remain distinct.

The anatomical mesh was generated with Meshy 7 and styled locally. Da Vinci’s circle, square and secondary pose are composed in Three.js.
