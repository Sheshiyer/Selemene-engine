# v3.0.0 Witness Prompt Quality Audit (All 16 Engines)

Date: 2026-03-03

## Standard
All witness prompts must satisfy:
1. End in `?`
2. Avoid prescriptive language (`you should`, `you must`)
3. Maintain reflective depth (non-trivial wording)
4. Preserve inquiry-first tone across consciousness levels
