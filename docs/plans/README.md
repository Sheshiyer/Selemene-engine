# Planning Materials

This folder is the canonical home for planning-oriented documentation that should not live alongside stable product/reference docs.

## What belongs here

- Roadmaps and timelines
- Launch/release checklists and execution plans
- Drill plans and one-time operational planning docs
- Design/implementation plans tied to dates or milestones

## Current layout

- `launch/`: launch-day checklists and launch execution docs
- `release/`: release process templates and checklists
- `drills/`: rollback and resilience drill plans
- Root files in this folder: dated plans, roadmap artifacts, and issue-plan bundles

## Naming suggestions

- Prefer dated names for time-bound plans: `YYYY-MM-DD-topic-plan.md`
- Keep reusable templates in subfolders (`release/`, `launch/`, `drills/`)
- Keep stable user/reference docs in other `docs/` sections
